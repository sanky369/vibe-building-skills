# Marketing Skills

12 agent skills that run a direct-response marketing system end to end: voice and positioning, keyword strategy, offers, copy, content, email, and distribution.

Every skill follows the authoring standard in [`docs/SKILL_SPEC.md`](../../docs/SKILL_SPEC.md): each is an operating procedure the agent executes, with intake questions, decision rules, a required output format, and a quality bar. Foundation skills produce artifacts (a Voice Guide, a Positioning Statement, a Keyword Map) that the production skills consume.

## The Skills

| Skill | Produces |
|---|---|
| **orchestrator** | A Marketing Route Plan — diagnoses the bottleneck and sequences the other 11 skills by dependency, naming the artifact each step passes forward |
| **brand-voice** | Voice Guide: archetype, dimensions at extremes, do/don'ts, before/after rewrites of real content |
| **positioning-angles** | Positioning Statement built from market stage, named mechanism, and a tested angle |
| **keyword-research** | Keyword Map via the 6 Circles Method, with cut list and verification queue |
| **lead-magnet** | Lead Magnet Spec plus the drafted asset itself |
| **direct-response-copy** | Conversion copy (landing pages, ads, sales emails) with hook alternates and a checkable conversion checklist |
| **seo-strategy** | SEO Strategy Document keyed to site stage (new / established / plateaued); deep playbook in `seo-strategy/references/` |
| **seo-content** | Search-intent-validated brief + full article + metadata + schema; templates in `seo-content/references/` |
| **newsletter** | Newsletter Blueprint (6 formats matched to situation) and fully drafted issues |
| **email-sequences** | Welcome / nurture / conversion / launch sequences with send-day maps and per-email drafts |
| **content-atomizer** | Atomization Pack: one seed piece repurposed into 5–7 fully written platform formats |
| **tweet-writer** | Tweet Package: researched hooks (3 distinct types), single tweets, threads; hook taxonomy in `tweet-writer/references/` |

## Where to Start

- **Unsure what's broken** → `orchestrator`. It routes by bottleneck (nobody knows us / traffic doesn't convert / can't scale / quality slipping).
- **No voice or positioning yet** → `brand-voice` then `positioning-angles`; the copy skills require both artifacts.
- **Product direction itself is unsettled** → step back to `skills/product-strategy/foundation-sprint` first.

## Ground Rules Baked Into Every Skill

- No invented statistics, testimonials, or fake scarcity — real proof or the section is restructured honestly.
- Counted limits are enforced (subject-line and hook character counts, one CTA per piece).
- Claims are cited or labeled as assumptions.
