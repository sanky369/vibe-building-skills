# Product Strategy Skills

Product strategy skills help you decide what to build before you invest heavily in execution. Use them when the product direction, customer, promise, differentiation, first experiment, or sprint workshop process is still unclear.

## Skills

1. **foundation-sprint** — Evaluate, pressure-test, or sharpen any product, feature, app, startup, or business idea using the Foundation Sprint method from Jake Knapp and John Zeratsky's *Click*.
2. **sprint-runner** — Run a facilitated Foundation Sprint, Design Sprint, or chained workshop with a virtual team, file-based sprint room, note-and-vote exercises, Decider calls, and resumable artifacts.

## Recommended Path

Start with **foundation-sprint** when you need to:

- Decide whether an idea is worth pursuing
- Clarify the target customer and painful problem
- Find differentiation against competitors and workarounds
- Compare multiple product approaches before building
- Turn the idea into a testable Founding Hypothesis

Start with **sprint-runner** when you need to:

- Facilitate a live sprint workshop rather than get a solo analysis
- Create a virtual team with productive disagreement
- Run note-and-vote, sketching, critique, and Decider-call exercises
- Produce persistent sprint artifacts in a file-based sprint room
- Resume a Foundation Sprint or Design Sprint across sessions

## Install

Install a skill folder directly:

```bash
skills/product-strategy/foundation-sprint/
skills/product-strategy/sprint-runner/
```
